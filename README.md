# 🚘 자동차 경주 미션
## 🎮 게임 규칙
1. 경주할 자동차 이름을 입력한다.
    - 자동차 이름은 쉼표(,)를 기준으로 구분한다.
    - 자동차 이름은 1자 이상 5자 이하만 가능하다.
    - 자동차 이름은 두 개 이상 입력한다.
    - 중복된 자동차 이름을 입력할 수 없다.

2. 몇 번의 이동을 할 것인지 입력한다.

3. 차수별 실행 결과를 출력한다.
    - 차수마다 각 자동차는 한 칸 전진 또는 정지한다.

4. 우승자 안내 문구를 출력한다.
    - 우승자는 한 명 이상일 수 있다.
    - 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.

## ✏️ 용어 정리
| 용어                | 설명 |
|-------------------|------|
| **Car**           | 하나의 자동차를 의미한다. |
| **name**          | 자동차의 이름을 의미한다. |
| **position**      | 자동차의 현재 위치(전진 횟수)를 의미한다. |
| **cars**          | 자동차들의 리스트를 의미한다. |
| **rounds**        | 자동차 경주를 시도할 총 횟수를 의미한다. |
| **parser**        | 문자열을 쉼표(,) 기준으로 분리하여 리스트 형태로 반환한다. |
| **MOVE_STANDARD** | 전진 또는 정지 여부를 결정하는 기준 상수(4 이상 시 전진)를 의미한다. |
| **MOVE_DISTANCE** | 자동차가 전진할 때 이동하는 칸 수를 나타내는 상수이다. |

## 📄 구현 기능 목록
- [x] 입력 관련 구현 사항
  - [x] 자동차 이름 입력 안내 문구 출력
  - [x] 자동차 이름 입력
    - [x] 빈 문자열 입력 시 에러 발생
    - [x] 중복된 자동차 이름을 입력 시 에러 발생
    - [x] 자동차 이름을 1개 이하 입력 시 에러 발생
    - [x] 자동차 이름이 5자 이상일 시 에러 발생
  - [x] 시도 횟수 입력
- [x] 결과 출력 관련 구현 사항
  - [x] 실행 결과 출력
    - [x] 실행 결과 안내문구 출력
    - [x] 자동차 경주는 시도 횟수 번 반복
    - [x] 각 라운드 별 자동차 별 위치 시각화(출력)
        - [x] 각 자동차는 매 라운드마다 0~9 사이의 무작위 값을 생성
        - [x] 생성된 값이 4 이상일 경우 전진, 3 이하일 경우 정지
  - [x] 우승자 출력
    - [x] 우승자가 없을 경우 에러 출력
    - [x] 우승자가 두 명 이상일 경우 쉼표(,)를 이용하여 구분
